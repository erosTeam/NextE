# 漫画翻译 Reader 端侧验收收口

状态：进行中<br>
最近复核：2026-07-27<br>
范围：只收口 Reader 的**端侧视觉翻译**。云端整图后端仍是独立路线，本计划不新增 provider、设置项或模型包。

## 要达成的结果

用户在 Reader 打开端侧翻译后，常规对白页应得到可阅读、没有互相覆盖或破坏画面的译图。端侧路线不能因为“检测到文字”就把艺术字、彩色拟声词或开放背景区域擦成白块；不能可靠回填时，保留原画优先于生成一张损坏的译图。

这不是“AI 辅助制图/导出完整译漫”工作流。端侧路线的目标是轻量阅读辅助；需要对艺术字、纹理背景和整页重绘有稳定质量时，走独立的整图云端路线。

## 固定边界

- 基线固定为 `YSGYolo + PP-OCRv5 + CTD + AOT 256`；不再重复尝试扩大 glyph mask、跨独立气泡合并、256px 切片或 LaMa large。它们已有真实页否决证据。
- 只使用真实、已授权的画廊/公版样本；不再用生成图或单页偶然截图作为质量结论。
- 一轮只允许一个直接对应已分类失败的候选。它必须先在开发页、再在跨画廊 holdout 页验证；任一关键反例退化即撤回。
- 不以“测试通过”“耗时变少”代替图像验收。替换文字、修复背景、文字方向和排版重叠分别检查。

## 三道完成门

### A. 无损优先门

在冻结的真实页集上，任何未被可靠闭合容器或像素 mask 支持的文本都不得触发破坏性消字/回填。验收：

1. 0 个跨气泡/标题-正文合并，0 个译文 layout 重叠；
2. 0 个明显的白色修复块、虚构纹理或气泡外擦除；
3. 对无法安全替换的块，原文保留且不叠加伪译文；
4. 常规闭合对白的已标注目标保持可阅读的视觉译文，不用“全部保留原文”虚假通过。

### B. 真实集门

用按画廊隔离的真实页面集报告标准对白、彩色/粗描边文字、开放背景/拟声词三类结果。开发集仅定位问题；至少一整个不同画廊的 holdout 决定候选去留。每页保存原图身份、OCR/document、render plan、阶段耗时和人工视觉判定，不重新消耗翻译请求来制造对比。

### C. 设备与发布门

在用户指定的 237 上，记录冷态一次和热态多页的 analysis/render 分项、AOT 调用数和峰值资源；签名构建、V2 decorator inventory、相关 Hypium 用例和真实 Reader 路径均通过。只有同时满足 A/B 后，才提交生产行为变更。

## 当前证据与下一条唯一工作线

2026-07-27 的真实彩色页与普通气泡页 A/B 证明，把 AOT glyph-mask 膨胀从 4px 降至 2px 没有消除彩色粗白描边/纹理修复伪影；该候选已撤回。耗时下降不构成质量收益。

同日，独立的 Torii 云端整图路线在设备 237 上用当前已配置的 `gemini-3.1-flash-lite` 完成两张内置原创页的真实上传、回图和应用内展示：总计 11.9 秒、产物共 3.8 MB。两页没有端侧 AOT 的白块；站牌本地化、拟声词语义和字距仍有可见缺陷。这只验证整图链路和基础视觉质量，不能外推为彩色艺术字画廊已经验收。

同日使用用户指定真实彩色画廊的 P45 与 P21 做了独立验证。P45 只有 URL，证明实际 Gallery Reader 的上传、回图和缓存替换，但不是质量样本。P21 含彩色背景、竖排气泡、描边和高密度对白；回图虽保留主体画面并生成中文，却留下多处日文原字，与译文叠在同一气泡内，且出现竖排溢出。因此当前 Torii 配置在真实高密度彩色页上**不满足可阅读成品**门槛。结论固定为：Torii 仅保留为用户显式选择的实验/备选整图路线，不作为端侧验收的退路，也不再为它做无边界的提示词、字体或参数调试。测试后已在设备 237 恢复“端侧处理”。

下一条工作线不是继续调 mask，而是对已冻结真实集运行当前基线的**无损优先审计**：将每个可绘制 block 按“可靠容器、可靠 glyph mask、不可安全替换”分类，先量化现有破坏性输出由哪一类触发；只在该分类能指出一个确定的错误准入条件后，提出单个 fail-closed 修复。若现有端侧模型对彩色/开放背景不能同时保留画面和回填文本，就把该类明确留给原文保留或独立整图云端路线，不再无限调参。

## 完成与停止条件

本计划只在以下两种情况下结束：

1. 有一个通过 A/B/C 的生产收口提交；或
2. 真实集证明当前模型在目标类别上没有安全修复路径，并已将端侧能力边界和云端整图分工写入设计文档。

这两者之外都不是“完成”；单个提交、局部测试、候选被否决或用户中途提问均不结束本计划。
