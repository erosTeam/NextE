# 漫画整图服务可行性调研

状态：结论已取得，无可接入候选<br>
最近复核：2026-07-27<br>
范围：只刷新并核对现有整图服务候选的官方 API、语言/图像能力、隐私保留、定价与接入边界；不新增 provider，不上传用户漫画页，也不请求或保存新的服务凭据。

## 已确定前提

- 端侧 `YSGYolo + PP-OCRv5 + CTD + AOT 256` 只保留为轻量阅读辅助，不能承诺复杂彩页成品质量；
- Torii 的 Lite 与当前目录最高档 Gemini 3.5 Flash 均在同一真实高密度彩页失败，不能作为默认成品路线；
- 任何新服务都必须是独立整图 backend，不能把其 OCR/inpaint/typeset 子接口拼回端侧管线。

## 本轮要产出的结论

对现有候选 PixLab 与 ImageTranslate.ai 做官方来源复核，筛出至多一个值得用户授权接入/试用的候选；若没有
满足日文漫画、成图返回、明确删除/保留与可接受计费的候选，明确记录“当前无可接入云端成品服务”。

## 门槛

1. API 能接收整页图片并返回完整可解码译图，支持日文到中文或官方明确支持相应语言；
2. 隐私条款明确图片、OCR 文本和结果的保留/训练语义，且不存在默认无限保留；
3. 有稳定认证、大小限制、超时/幂等或可等价实现的重复扣费边界；
4. 公开价格能按单页估算；
5. 在没有用户专用 Key 和图片上传授权前，只做协议/条款调研，不接入代码也不做真实页请求。

## 结束条件

只在官方资料支持一个可试用候选，或所有候选明确不满足任一门槛时结束。前者会把数据转交、费用与新 credential
边界作为单独用户决策返回，绝不静默接入。

## 复核结果

- **ImageTranslate.ai：不通过。** 官方 API 的 `manga` 模式、日文/中文、base64 成图、20 MB 上限、Bearer
  认证和 `Idempotency-Key` 都满足接口门槛；但其隐私政策（2026-02-06 生效）明确默认无限期保留数据，条款
  还允许为提供、改进和维护服务而处理、分析和存储上传内容。因此不满足隐私保留门槛。
- **PixLab：不通过。** 官方 `imgtranslate` API 支持 `ja`/`zh`、multipart 上传与 base64/原始二进制成图，
  隐私政策明确默认内存处理并自动清除、除非显式导出或存储不会保留、不可识别输入输出不用于训练；但公开价格未
  指明该 endpoint 的计量类别或每页单位，并在同页给出 `$0.07/1,000` 和 `$0.009/1,000` 两种超额说明。无法
  估算单页成本或约束重试扣费。

两者均没有进入真实请求、代码接入或凭据保存。本计划到此结束并归档；后续只有用户明确接受数据/费用边界，或
厂商公开改变上述合同事实时，才重新建立新的、单一 provider 的授权计划。
